# Value Proposition Draft — 예술품 재분배 × 미술품 토큰증권 가치순환 플랫폼

> **단계:** 02_VPS-Drafts 1단계(초안). [PRD-From-VPS-Sample](https://github.com/wild-mental/PRD-From-VPS-Sample/tree/main/02_VPS-Drafts)의 `01_value-proposition-draft.md`에 대응한다.
>
> ⚠️ **작업 방식의 차이를 밝힌다.** 샘플 저장소는 이 단계 이후 **두 개의 서로 다른 AI 모델(Gemini/Opus)로 각각 VPS를 뽑아 비교·병합**하는 `03_value-proposition-sheet_*` · `04_analysis_vps_comparison.md` 단계를 거친다. 이 저장소는 단일 모델(Claude)로 순차 작업했으므로 그 비교 단계를 실제로 수행하지 않았다 — 존재하지 않은 비교를 지어내지 않는다. 대신 이 초안은 [챕터 09 공식본](../09-value-proposition/value-proposition-03-art-redistribution-platform-v1.0.md)으로 한 번 정리된 뒤, [04_VPS-final](../04_VPS-final/)에서 전체 리서치를 직접 포함(rooting)하는 형태로 최종화됐다.

---

이 초안은 [챕터 04~08](../04-tam-sam-som/)의 산출물을 처음으로 하나의 Value Proposition Sheet 구조로 정리한 버전이다 — Pain/Needs → JTBD Goal/Job → Desired Outcome → Value Proposition → Competitor/Substitute → Differential Value → Proof의 7항목([강사 09 방법론](https://wildmental.notion.site/09-PRD-Product-Requirement-Document-3b7d03212bd480adb9f6f0a51c974b05) 기준).

## 요약

| 항목 | 초안 시점의 내용 |
|---|---|
| 핵심 Pain | 작품+이전비용이 분리돼 실행이 멈춤(Gate2) · 목적별 권리 미분리로 승인이 막힘(Gate1) |
| JTBD | 8개 페르소나(R1~R8)의 Situation·Job Statement |
| Outcome | O01~O15(+O08 반증) — DOS(SAM) 내림차순 |
| Value Proposition | "쓰임이 끊긴 작품에게 다음 쓰임을 만들고, 그 쓰임을 작품별로 남긴다" |
| Proof | 다섯 경로 수렴(TAM-SAM-SOM·경쟁AOS재판정·비어있는세자리·JTBD·외부실측) |

전문은 [챕터 09 공식본 (value-proposition-03-art-redistribution-platform-v1.0.md)](../09-value-proposition/value-proposition-03-art-redistribution-platform-v1.0.md) 참조 — 이 초안이 정리되어 공식 커리큘럼 챕터 09 형식(7섹션)으로 남은 결과물이다.
