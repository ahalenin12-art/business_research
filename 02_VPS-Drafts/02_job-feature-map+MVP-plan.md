## 2. 현실 근거 기반 리스크 및 대응 전략

### 🔴 F1 리스크: Funding 실제 지불 의사 미검증

- **현실 상황:** 개인·기업의 이전비용 지불 의사는 챕터 04~08 전체에서 실측된 적이 없다 — 이 사업 전체에서 **가장 크고 유일한 1순위 검증 항목**이다.
- **대응:** 파일럿 1건에서 실제 이전비용(운송·보험·설치)을 시민 Funding으로 완결시키는 것을 최우선 목표로 삼는다. 목표 미달 시 어떤 금액도 집행하지 않는 에스크로 원칙을 둔다.

### 🔴 F2 리스크: 4단 동의가 법무 검토 없이는 실효성 없음

- **현실 상황:** 박소연·서재원 모두 "재분배 동의≠상업활용 동의≠증권연계 동의" 분리를 요구하지만 실제 계약 템플릿은 존재하지 않는다.
- **대응:** [국립현대미술관 미술은행의 기존 대여계약·상태확인서 서식](../01_Biz-Analysis/2_competitors-analysis.md)을 참고해 법무 검토를 거친 표준 동의서를 MVP 착수 전 확정한다.

### 🔴 F3 리스크: '낙인 없는 프레이밍'이 표본 1명(R8)의 과잉해석일 수 있음

- **현실 상황:** JTBD는 모의 응답(가정 위의 가정)이며, R8 표본은 1명이다.
- **대응:** 참여 포기 작가 표본을 8명 이상으로 확대 인터뷰한 뒤 UX 언어를 확정한다. 그 전까지는 가설 딱지를 유지한다.

## 3. MVP 개발 범위에서 제외 (Out of Scope)

1. **가치상승 서사 대시보드** — O08 DOS 음수로 반증, 로드맵에서 제외
2. **토큰증권 발행·유통 기능** — 2027-02-04 제도 시행 전, 별도 규제상품
3. **학교·기관 안전조건 필터·청중별 대시보드 고도화** — DOS 5.0 이하로 MVP 다음 단계
