# business_research

산업 및 비즈니스 분석 실습 저장소입니다. 프레임워크를 실제 시장에 적용한 분석 산출물을 주제별로 관리합니다.

## 분석 방법론

모든 분석은 아래 순서를 따릅니다. 각 단계의 산출물이 다음 단계의 입력 컨텍스트가 됩니다.

```
Step 0  시장 영역 좁히기            (사람이 수행)
Step 1  비즈니스 기획 초안 작성      PARTS+C 프롬프트
Step 2  개별 5 Forces 분석          SMARTER 프롬프트
Step 3  두 시장 비교 분석
Step 4  가치 사슬 분석
Step 5  핵심 성공 요인(KSF) 도출
```

> **Step 0은 자동화되지 않습니다.** PARTS+C 템플릿의 플레이스홀더를 비운 채 실행하면 기획서가 아니라 "어떤 사업을 할지 정하는 문서"가 나옵니다. 시장을 좁히는 작업은 반드시 사람이 먼저 끝내야 합니다.

## 분석 주제

### [01. 에너지·전력 — 전력을 파는 두 가지 방법](./01-energy-power/)

같은 전력 산업 안에서 사업 모델이 정반대인 두 시장을 챕터 01~03에 걸쳐 비교 분석했습니다.

| 구분 | 시장 A | 시장 B |
|---|---|---|
| 시장 영역 | 수도권 **AI 데이터센터 코로케이션** | 중견·중소 제조기업 대상 **재생에너지 PPA 중개·계약관리** |
| 사업 자산 | 자산집약 (프로젝트당 수천억~1조원) | 자산경량 (인력·데이터 중심) |
| 희소 자원 | 계통 접속 승인, 전력 확보 부지 | 발전량 예측 정확도, 장기계약 신용 중개 역량 |
| 종합 매력도 | **높음** | **낮음** |

- **완료 챕터**: 01(5 Forces) · 02(가치 사슬) · 03(KSF)
- **핵심 결론**: 두 시장은 같은 병목(계통 포화) 위에 있으나 매력도가 정반대입니다. 차이를 만드는 변수는 하나입니다 — **희소 자원을 소유하는가, 아니면 그것을 다루는 서비스를 팔 뿐인가.**
- **산출물**: 마크다운 9종 + 통합 워드 보고서 1종

## 작성 원칙

- **수치는 검증된 것만 사용합니다.** 출처가 확인되지 않은 항목은 본문에 '추정' 또는 '미확인'으로 명시합니다.
- **강도 판정 기준을 통일합니다.** 5 Forces의 '강함/중간/약함'은 "해당 힘이 산업 평균 수익률을 깎아내리는 정도"로 정의합니다.
- **공공 부문을 반드시 분석에 포함합니다.** 규제 산업에서 정부·공기업은 공급자·경쟁자·규제자·대체재 공급자 역할을 동시에 수행합니다.
- **자산집약 시장은 시점을 명시합니다.** 준공까지 수년이 걸리는 사업에서 "지금 매력적"은 판단 근거가 되지 못합니다.
